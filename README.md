# Smart Home 3D Interactive Showcase

Interactive 3D presentation for the Smart Home project.

## Run

```powershell
npm install
npm run dev
```

## Build

```powershell
npm run build
```

## Notes

- The current app is the Milestone 0.1 technical foundation from `SMART_HOME_3D_AGENT_PLAN.md`.
- `_legacy_vanilla_index.html` preserves the previous tuned single-file Three.js build and must be used as the source for camera/device data.
- `_source_konfigurator.html` is the configurator reference for package, module, pricing, and metrics logic.
